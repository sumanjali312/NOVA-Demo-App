# NOVA Demo Application

This is a simple browser-based demo of the fictional NOVA Team Productivity Platform from the Software Testing Intern assignment.

## Features
- Registration and login
- Logout
- Dashboard
- Project create/edit/delete
- Add members count
- Task create/edit/delete
- Assign tasks
- Priority
- Status
- Due date
- Comments
- Search tasks/projects
- Filter tasks by status and priority
- Notifications
- Profile update
- Local demo data storage

## How to run
1. Extract the ZIP.
2. Open `index.html` in Chrome or Edge.
3. Use:
   - Email: `demo@nova.test`
   - Password: `password`
4. Start testing and capture screenshots as evidence.

No server or database is required for this first demo version. Data is stored in the browser's localStorage.

## QA note
This demo is intentionally simple so it can be used as the system-under-test for the assignment. Do not describe untested behavior as an actual defect. For the final QA report, record only defects you can reproduce and provide evidence.
